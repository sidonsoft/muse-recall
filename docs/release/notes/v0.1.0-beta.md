# Release notes: v0.1.0 (first beta)

**Status: draft. Not to be tagged, released or promoted to `main` without the owner's go.**
This describes what Muse Recall v0.1.0 does. It is written for someone meeting the
product for the first time, so it states capabilities, not history.

---

Muse Recall is a local-first HTML Studio for Meta's Muse Spark with correctable project
memory. It is a local, single-user beta: loopback only, no hosted service.

## What it does

**Remembers and corrects**
- Project decisions are stored with provenance, confidence and revision history. A
  correction supersedes the old decision, which stays auditable but is no longer retrieved.
- Memory can be exported and imported with versions and round-trip checks, and a review
  queue surfaces stale claims. A timeline and relationship map show how decisions relate.

**Keeps changes under review**
- Every generated change is staged with preview, source and diff. Approval publishes the
  exact bytes that were checked; rollback follows recorded ancestry.
- An advisory Decision Guard cites the decisions behind each finding and never blocks approval.

**Connects to other tools**
- A REST API with pagination and a machine-readable error catalogue, and an MCP stdio
  server over one shared tool contract (seven tools).
- `Idempotency-Key` replay on retry-sensitive writes, and an optional shared bearer token
  for deliberate network exposure (loopback is the default).

**Built to be operated**
- Durable Forge jobs with restart recovery, a repair path for damaged state, and
  power-loss-safe writes.
- Backup and restore with a standing drill, operator runbooks (upgrade, rollback,
  incident, disaster recovery), health alert signals and a cron-ready alert prober.
- A managed browser verification workflow on Chromium and Firefox, an adversarial test
  suite for the access-control layers, and CI that re-verifies the research evidence.

## Known limits

- Local single-user beta; the default posture has no authentication.
- Error responses for malformed JSON and oversized bodies use `internal_error`
  (KI-43/45/48). The catalogue fix is planned.
- Worker uid isolation for Forge needs an operator-provisioned ACL (KI-49).
- Tests run in CI but are not typechecked.
