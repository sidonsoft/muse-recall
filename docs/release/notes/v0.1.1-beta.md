# Muse Recall v0.1.1 beta

This patch release brings the published download up to date with the deployed judge experience. It supersedes v0.1.0 as the latest release; v0.1.0 and its assets remain unchanged historical records.

## What changed since v0.1.0

- Three explicit judge paths: credential-free offline exploration, live application generation through the Muse Code CLI, and live media/SAM with a separate server-side key.
- One read-only setup panel in the terminal, System screen, health response and `pnpm judge:check`. It checks local prerequisites and demo record/version/artifact integrity; login, provider access and quota remain unverified.
- Bounded, redacted readiness diagnostics for long model IDs, CLI paths and project names. The readiness panel and approval runtime share browser-policy resolution, including the legacy Chrome setting and invalid-value handling.
- Correct submission and preservation records, separating entry confirmation, update verification and the observed source snapshot from the unknown original submitted commit.
- A website judge-path card, accurate Codespaces scope, and a six-card layout.
- The worktree-aware verification fix and production CI coverage added after v0.1.0.
- Package manifests, the API service version and the MCP default identity now report 0.1.1.

## Try it

Requires Node.js 24+ and pnpm 10.x (workspace pin: 10.32.1).

```sh
git clone --branch v0.1.1 https://github.com/sidonsoft/muse-recall.git
cd muse-recall
pnpm install --frozen-lockfile
pnpm judge:check
pnpm demo:seed
MODEL_PROVIDER=echo pnpm dev
```

Open http://127.0.0.1:5173. Offline exploration supports browsing and chat, not Studio application generation. Re-running the seed resets the demo workspace. Live generation requires an installed, logged-in Muse Code CLI and a verification browser; media operations require a separate server-side `FORGE_MUSE_API_KEY` and quota.

## Verification and release identity

The GitHub release records the exact tagged commit and links its CI. Attached source and verification evidence belong to that commit; `SHA256SUMS` identifies the published assets. Ten offline production gates validate workflows and controls with deterministic providers; they do not establish generated-application quality or live provider availability.

## Limits

Single-user local beta, loopback by default, optional shared bearer access, no accounts or hosted collaboration, and one generated HTML document per application. Guard and screenshot findings are advisory. Approval checks loading, not every interaction, accessibility or output quality. Live inference sends selected inputs to the provider and may incur charges. Codespaces generation has not been exercised. Existing Vite/esbuild development-tool advisories remain separate maintenance.

This release does not modify a hackathon entry or identify the unknown original submitted tree. Frozen tags and checksummed research/demo evidence are unchanged.
